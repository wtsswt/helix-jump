# 螺旋坠落 · Helix Drop

单文件 Canvas 螺旋塔下落小游戏：小球自己在弹，转塔把缺口送到它脚下。

## 玩法

球**永远在自己弹**，你控制不了它，能操作的只有转塔。

- 转塔：左右拖动（鼠标或手指），或按 `←` `→`（`A` `D`）
- 缺口转到球正下方，球就掉到下一层，**那一层随即碎裂消失**
- 盘上有黑色带锯齿的扇区，球落上去就爆。缺口两侧各留了一段纯红缓冲带，落偏一点还有救
- 连续穿透三层，球会燃起来，下一层不管红黑直接砸穿（一次性）
- 撞上黑色扇区就结束

## 设计上的几个决定

**球为什么一直弹**
球落到盘上不是停住，而是立刻给一个固定向上的初速度，落回来再弹，周期约 0.42 秒。
玩家就是在这个节奏里找机会转塔。停下来等操作会让整个游戏变成"回合制"，节奏就散了。

**层为什么那么"开"**
层间距 0.84、盘半径 1.0、俯视压扁系数 0.26。弹起高度 0.32，球直径 0.26，
所以球弹到最高点时球顶还在上一层的底面之下（0.58 < 0.84），既看得到弹跳又不会穿模。

**危险为什么是一段而不是一整层**
危险区是盘上的一个扇形（0.42–0.86 rad），不是整层。整层危险等于没有可通过的路，
玩家只能靠 0 误差去撞缺口，那不叫难度，叫劝退。现在缺口两侧最少留 0.58 rad 的纯红缓冲带。

**为什么要预警**
球正下方那层如果会要命，整层外缘会红色脉冲发光、屏幕四边泛红。
球下一次落地有一瞬间的滞空，这层提示就是给玩家的反应窗口。

## 功能

- 无尽塔，越深缺口越窄（1.34 → 0.74 rad），危险扇区越密
- 连穿计分：第 n 连给 `10 + (n-1)×6` 分，连穿三层点燃火球
- 碎盘：穿过的整层炸成扇形碎块飞散
- 危险预警：目标层红色脉冲描边 + 屏幕边缘泛红
- 最高分存 localStorage，音效开关同样记忆
- 音效全部 WebAudio 实时合成（弹跳随次数变调、穿层随连穿升调、砸穿噪波），无音频文件
- 暂停（`空格` / `Esc` / `P` / 右上角按钮），切后台自动暂停
- 全端响应式：320 / 375 / 390 / 430 / 768 / 1024 / 1440 及横屏均无溢出

## 技术

纯 `index.html` 单文件，无框架、无构建、无外部依赖。

- 投影：世界点 `(r·cosθ, y, r·sinθ)` → `x = cx + r·cosθ·s`，`y = baseY + (camY - y)·s + r·sinθ·0.26·s`，
  即俯视压扁的等轴测。盘的椭圆参数角与极角一致，所以能直接用 `ctx.ellipse` 画扇形环带
- 层级遮挡：按世界高度从低到高绘制，高的后画盖住低的（画家算法）
- 判定：球心角（固定为 0）与缺口中心角之差，窗口 `gapW/2 − 0.58·asin(r/ORBIT)`；
  危险判定要求球心明显压进扇区（`h.w/2 − 0.45·asin(r/ORBIT)`），球边缘擦到不算死
- 物理：固定重力 −15，落在盘面时 `vy = √(2g·0.32)` 起跳，没有静态状态，所以不存在"卡住不动"
- 难度：`gapW = max(0.74, 1.34 − 0.0055i)`，危险扇区数量随 i 概率从 0 增至最多 3 段

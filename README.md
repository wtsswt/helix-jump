# 螺旋弹球 · Helix Jump

单文件 Canvas 螺旋塔下落小游戏：转动塔身让小球穿过缺口一路坠底。

一个跑在浏览器里的「旋转螺旋塔」小游戏。塔由一层层带缺口的西瓜切片叠成，小球停在某一层上，
左右拖动塔身把缺口转到球的正下方，球就会掉下去，一直掉到撞上红色尖刺层为止。

## 玩法

- 转塔：鼠标/手指左右拖动，或按 `←` `→`（`A` `D`）
- 目标：让球穿过缺口不断下落，深度越深分数越高
- 危险：从第 10 层开始出现发红光的尖刺层，撞上立即结束
- 连穿：一次下落连续穿过 2 层以上会额外加分并提示连穿数

## 功能

- 无尽模式，深度越深缺口越窄、尖刺层越密
- 连穿计分：第 1 层 10 分，之后每层递增 6 分，落地结算连穿奖励
- 最高分本地保存（localStorage），音效开关同样记忆
- 粒子碎屑、死亡爆炸、屏幕震动、球体透视轮廓（被层挡住也能看见球）
- WebAudio 实时合成音效，不依赖任何音频文件
- 暂停 / 继续（`空格`、`Esc`、`P` 或右上角按钮），切后台自动暂停
- 全端响应式：手机竖屏、横屏、平板、桌面自适应

## 技术

纯 `index.html` 单文件，无框架、无构建、无外部依赖。

- 渲染：Canvas 2D 手写等轴测投影（`screen_y = -y·s + z·TILT·s`），层按世界高度排序做画家算法遮挡
- 每层是「椭圆扇形 + 下移一份的深色副本」拼出的厚度感，缺口为径向扇形
- 物理：定步长重力 + 逐层顶面穿越检测，帧率无关（delta time）
- 判定：球心角与缺口中心角之差，扣掉球的角半径 `asin(r / R)` 即实际可通窗口
- 难度曲线：`gapW = 1.15 - 0.50 × min(1, depth/70)`，尖刺概率 `min(0.30, (depth-9)×0.026)`

## 本地运行

```bash
python3 -m http.server 8000
# 或直接双击 index.html
```
